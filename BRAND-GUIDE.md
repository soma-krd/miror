# Mir — Brand Guide

This document defines the Mir brand identity: name, symbol, color palette, typography, and usage rules. All assets live in `src-tauri/icons/` and `public/`.

---

## Brand Name

**Mir** (pronounced "meer")

The name carries two intentional meanings:

1. **Mir means "peace" in Russian** — Mir brings order and calm to chaotic multi-service dev environments.
2. **Mir was the iconic modular space station** — composed of multiple docked modules working as one. This is exactly Mir's purpose: manage multiple docked dev services (frontend, backend, workers, databases) as one unified command module.

**Tagline**: *Command module for local dev*

**Do not**:
- Capitalize as "MIR" (it's not an acronym)
- Spell as "Mïr", "Myr", or "Mire"
- Add a period after the name ("Mir." is wrong, except at end of sentence)

## Brand Symbol

The Mir symbol is a **hexagonal command module** containing a **run chevron** and a **status dot**.

```
    ╱─────╲
   ╱  ▸ ●  ╲      Hexagon = command module / container
  │        │      Chevron ▸ = run / terminal prompt
  │        │      Dot ● = live status indicator
   ╲       ╱
    ╲─────╱
```

### Design rationale

| Element | Meaning |
|---------|---------|
| **Hexagon** | The command module — stability, structure, the container that holds services. A hexagon is the most efficient tessellating shape in nature (honeycomb), suggesting modularity and efficient organization. |
| **Chevron (▸)** | The run / terminal prompt — forward motion, action, "execute." Universally readable as "start" across cultures. |
| **Status dot (●)** | The monitoring indicator — Mir is always watching your services. The amber color signals "alive and active" without using green (which is reserved for the hexagon/brand). |

### Clear space

Always maintain clear space equal to the height of the chevron around the symbol. No other elements should intrude into this space.

### Minimum size

- **Digital**: 16×16 px (tray icon size)
- **Print**: 24×24 mm

Below these sizes, the status dot becomes invisible and should be omitted.

- All text colors meet WCAG AA contrast (4.5:1) against the Slate-900 background.
- The Emerald-500 hexagon outline meets AA against Slate-900.
- The Amber-400 status dot meets AA against Slate-900.
- **Do not** place Emerald-500 text on Slate-800 (fails contrast) — use Emerald-400 instead.

## Typography

### Primary typeface: Geist Sans

- **Headings / Wordmark**: Geist Sans Bold (700)
- **Body**: Geist Sans Regular (400)
- **Small text / labels**: Geist Sans Medium (500) at 10-12px
- **Mono / code / logs**: Geist Mono Regular (400)

Geist is loaded via Next.js font optimization in `src/app/layout.tsx`. It's a modern geometric sans-serif designed by Vercel — clean, technical, and readable at small sizes.

### Fallbacks

```
font-family: 'Geist Sans', 'Inter', 'Helvetica Neue', system-ui, sans-serif;
```

For SVGs (which can't embed fonts), use the fallback chain `'Geist Sans', 'Inter', system-ui, sans-serif`.

### Wordmark

The wordmark is **"Mir"** set in Geist Sans Bold, lowercase except for the capital "M". The "i" has its dot replaced with a small emerald diamond (rotated 45° square) as a subtle brand detail.

- Letter-spacing: -0.5 (tight)
- Color: Slate-100 on dark backgrounds, Slate-900 on light backgrounds

## Logo Variants

### 1. App icon (1024×1024 source)

**File**: `src-tauri/icons/app-icon-1024.png`

Rounded-square iOS/macOS-style icon. Slate-900 background with subtle gradient, emerald hexagon, white chevron, amber status dot.

Used for:
- macOS `.icns` (generated by `cargo tauri icon`)
- Windows `.ico` (generated as `icon.ico`)
- Linux `.png` (used directly by AppImage/desktop entry)

### 2. Brand symbol (SVG)

**File**: `src-tauri/icons/mir-symbol.svg`

The hexagon + chevron + dot, without the background square. Transparent background. Use in:
- Sidebar (small)
- About dialog (large)
- Marketing materials

### 3. Full logo with wordmark (SVG)

**File**: `src-tauri/icons/mir-logo.svg`

Symbol + "Mir" text. Horizontal layout. Use for:
- Splash screens
- README headers
- Social media
- Presentation slides

### 4. Sidebar logo (SVG, compact)

**File**: `public/mir-sidebar-logo.svg`

Compact horizontal layout sized for the app sidebar (180×32 viewBox).

### 5. Favicon (SVG)

**File**: `public/mir-favicon.svg`

Full app icon as SVG — renders crisply at 16×16 up to 512×512. Modern browsers prefer SVG favicons over .ico.

### 6. Tray icon — template (macOS)

**File**: `src-tauri/icons/tray-icon-template.png` (22×22)

Pure white with alpha, no background. macOS renders template images as black in light mode, white in dark mode. This is the correct format for menu bar icons per Apple's Human Interface Guidelines.

### 7. Tray icon — colored (Linux/Windows)

**File**: `src-tauri/icons/tray-icon-22.png` (and 16/32/48/64)

Emerald hexagon + bright emerald chevron + amber dot, on transparent background. Used by Linux (AppIndicator) and Windows (system tray) which don't support template images.

## Usage Rules

### Do

- Use the symbol on Slate-900 or white backgrounds
- Maintain clear space around the symbol
- Use the template variant for macOS menu bar
- Use the colored variant for Linux/Windows tray
- Keep the hexagon stroke width proportional to the symbol size (≈8% of the hexagon radius)

### Don't

- Don't recolor the hexagon — emerald is the brand color
- Don't rotate the symbol
- Don't add drop shadows or bevels
- Don't stretch or distort the aspect ratio
- Don't place the symbol on busy backgrounds without a solid container
- Don't use the colored tray icon on macOS (use the template variant)

## Regenerating Assets

All assets are generated by `scripts/generate-mir-icons.py`:

```bash
python3 scripts/generate-mir-icons.py
```

This regenerates all PNGs and the .ico. SVGs are hand-authored and should be edited directly.

To generate platform-specific icon formats (`.icns` for macOS, additional `.ico` sizes for Windows), run Tauri's icon generator locally:

```bash
cd src-tauri
cargo tauri icon icons/app-icon-1024.png
# Generates: 32x32.png, 128x128.png, 128x128@2x.png, icon.icns, icon.ico, Square*Logo.png
```

## Brand Voice

Mir's voice is **calm, technical, and direct** — like an air traffic controller.

- **Calm**: Never use exclamation marks in UI copy. Use periods. State facts.
- **Technical**: Use precise terminology (PID, SIGTERM, stdout) without over-explaining.
- **Direct**: Prefer "Stop" over "Halt service", "Start" over "Initialize", "Crashed" over "Encountered an error".

**Examples**:
- ✅ "Redis crashed (exit code 1)"
- ❌ "Oops! Redis encountered an unexpected issue! 😱"
- ✅ "3 of 4 services running"
- ❌ "You're doing great! Most services are up!"
